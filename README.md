# 余烬防线 · EMBERLINE

从原来的手搓坦克大战重制而来。驾驶战车保卫水晶核心，完成六波防守并击败「灰烬之王」。支持单人、本地双人和触屏。

## 开始游戏

在仓库目录运行（需要 Python 3）：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 **http://127.0.0.1:8000/index.htm**，点击「启动引擎」。停止服务器按 `Ctrl+C`。请通过 HTTP 打开，ES Modules 不能直接从 `file://` 运行。首次点击会按浏览器规则解锁声音；右上角或 `M` 可静音。字体、绘图与合成音频全部本地运行，无运行时网络依赖。

旧版保留在 **http://127.0.0.1:8000/legacy.htm**。

## 怎么玩

- **目标**：保卫地图下方的水晶核心。敌军包括掠袭者、突击战车、远射猎手、重装堡垒和双阶段最终首领。
- **玩家 1**：`WASD` 移动，鼠标瞄准，按住左键或 `空格` 开火。`Shift` 冲刺，`Q` 震荡爆破，`F` 切换自动开火。
- **玩家 2**：方向键移动，自动瞄准附近敌军，按住 `小键盘 0` 或 `Enter` 开火。`小键盘 1` / `右 Shift` 冲刺，`小键盘 2` / `右 Ctrl` 震荡。
- **触屏**：左摇杆移动，右侧开火与技能按钮，自动瞄准。横屏可获得更大的战场视野。
- **全局**：`Esc` / `P` 暂停；切出页面自动暂停。右上角提供操作手册和全屏。
- **成长**：清波后全员修复 35 装甲、核心修复 15 耐久，三选一改装对全队生效。维修模块自动吸附，修复 22 装甲及 8 核心耐久。
- **重建**：战车阵亡 7 秒后消耗核心 40 耐久重建。全员阵亡且能量不足，或核心被击毁，行动失败。

## 代码与美术

新入口 `js/main.js` 连接输入和界面；`js/game.js` 是独立战斗模拟；`js/renderer.js` 负责程序化工业废墟、分层坦克、晶体、弹道、爆炸和雷达；`js/sound.js` 用 Web Audio 混合炮火与动态节拍，`js/synthesis.js` 生成缓存的战斗 PCM 音色；`js/config.js` 配置波次、敌军和改装。

浏览器页面按 `100dvh` 固定布局，战场从剩余高度取空间；较长的手册在模态自身滚动。命中采用整车纯白闪、方向镜头回弹、装甲视觉震颤和短停顿，击毁触发限频的战场白闪；普通命中、击毁和首领爆炸使用三级震屏；枪口、穿甲命中与爆炸拥有独立阶段。声音包含炮口压力、金属瞬态、低频滚动和短反射；音乐独立混音，在重爆炸时短暂避让。

静态背景离屏缓存，所有战斗逻辑使用同一秒制时钟。炮弹使用线段碰撞，冲刺分段检测墙体，暂停不推进战斗与冷却。粒子与残骸有数量上限。设置与最高分只保存在当前浏览器 localStorage；禁用存储时仍可游玩。

原始模块、`image/`、`audio/`、`legacy.css` 和 `js/legacy-main.js` 用于旧版。`fonts/ChakraPetch-Bold.ttf` 来自 Google Fonts 的 Chakra Petch，授权见同目录 OFL 文件。新美术与音效均由代码生成。

## 验证

Node.js 22 或更新版本可直接运行，无需安装依赖：

```powershell
node --test tests/game.test.mjs tests/synthesis.test.mjs
git diff --check
```

规则回归覆盖弹道、掩体、冲刺、震荡、无敌帧、友军保护、暂停、重建、双人升级、六波结算、重开及维修。浏览器检查需额外验证画面、键鼠/触屏输入和声音；自动化测试不能代替真人对手感与难度的判断。
